# PasswordGenerator

Программа для генерации пароля.

Входными параметрами являются:
- вероятность подбора пароля злоумышленником P;
- скорость перебора паролей (паролей / секунду) V;
- срок действия пароля (дней) T;
- используемый алфавит.

На основе введенных данных программа:
- вычисляет и выводит нижнюю границу S*;
- выводит мощность выбранного алфавита A;
- определяет и выводит минимальную длину пароля L;
- формирует случайную последовательность символов длины L, используя символы выбранного алфавита.

---

*Параметр P вводится в виде "0", "0.1", "1" и подобном.

---

## Цели и задачи

### Цели проекта
- Автоматизация расчёта стойкости пароля — cгенерировать математически обоснованный по длине пароль, исходя из заданных условий безопасности.
- Повышение безопасности учётных данных — генерировать пароли, устойчивые к подбору за заданный срок действия.
- Учебно-демонстрационная цель.

### Какую бизнес-задачу решал бы такой проект
В бизнес-контексте PasswordGenerator решает задачи:
- Генерация паролей для сотрудников/сервисов — вместо «придуманных» паролей выдаются случайные нужной длины.
- Обучение сотрудников — наглядная демонстрация, почему длина пароля важнее «сложности» и как скорость перебора влияет на требуемую стойкость.
